# 🎓 Student & College Record Management System

A console-based management system written in C that handles student information, academic grades, and administrative operations using structured data and file handling.

---

## 📌 Features

- **Student Registration:** Add new student records, roll numbers, and personal details.
- **Academic Grading:** Record, update, and manage subject marks and calculate percentages/grades.
- **Search & Lookup:** Search records by Roll Number or Name for quick retrieval.
- **Display Records:** Tabulate and print stored student entries cleanly in the terminal.
- **Persistent Storage:** Saves and reads records directly to/from disk using file operations (`fopen`, `fread`, `fwrite`, or `fprintf`).

---
